::: zh
**监听（monitoring）** 是在工作间里建立可信判断：用熟悉、校准过的音箱或耳机，听清混音里发生了什么，而不是听它是否讨喜。音箱与房间共同决定你听到的声音，换一套系统就等于换一个判断基准。

做法上先固定一套主监听，用参考曲目校准；再备一副耳机和一只小音箱交叉验证。音量保持在中等偏低，长时间大音量会让听觉疲劳、低频判断变钝。**通行说法**是监听不比谁的低频更猛，而比谁更少说谎。

常见误解是把监听当成发烧友的好听系统。监听追求中性、可复现，好听可以留给客厅；若房间有强烈驻波，再贵的音箱也只能如实放大问题。
:::

::: en
**Monitoring** is building a trustworthy reference in the workspace: hearing what a mix contains on a familiar, calibrated speaker or headphone system, not whether it flatters. Monitors and room together shape what reaches the ears, so changing the system changes the baseline.

Start with one main pair, calibrated against reference tracks, then cross-check on headphones and a small speaker. Keep levels moderate; long loud sessions tire the ear and blur low-end judgement. The common view is that monitoring is not about the biggest bass but about lying least.

The usual mistake is treating monitors as a hi-fi system for pleasure. Monitoring aims at neutral, repeatable sound; pleasure can wait for the living room. In a room with strong standing waves, even costly speakers only magnify the problem.
:::
