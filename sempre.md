::: zh
**sempre（始终、一直）** 是修饰语：**sempre legato** 是「始终连奏」，**sempre forte** 是「始终保持强」。它把某个要求**延伸到整段**，而不是只作用于一个音。

它和重复写记号不同：sempre 是概括性的持续指示，谱面不必每个音都标。常见误解是把 sempre 当成「渐强」——它不表示变化，恰恰表示保持；看到 sempre，先问它要求保持的是哪一种状态。

::: en
**Sempre** ("always") is a modifier: **sempre legato** means "legato throughout", **sempre forte** "loud throughout". It extends a requirement **across a whole passage** rather than applying it to one note.

It differs from writing the mark on every note: sempre is a summary instruction to continue, so the score need not repeat it. The usual mistake is to read sempre as a crescendo — it does not mark change but persistence; when you see sempre, ask which state is to be kept.
