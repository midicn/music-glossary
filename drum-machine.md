## 五语对照

| 语种 | 名称 |
|---|---|
| 中文 | 鼓机 |
| 英语 | drum machine |
| 意大利语 | drum machine（借英语；亦说 macchina ritmica） |
| 德语 | Drumcomputer / Rhythmusmaschine |
| 法语 | boîte à rythmes |

**鼓机** 是按预设音序自动播放打击乐音的电子乐器，声音由合成或采样产生。英语 drum machine 直译「鼓的机器」，法语 boîte à rythmes 意为「节奏盒」，德语 Drumcomputer 则把它归入计算机。三个名字各抓住一面：机器、盒子、程序。

**常见混淆**：鼓机不是鼓组，也不等于电子鼓。鼓组由人击打，电子鼓是可击打的电子套鼓；鼓机更像一台会打鼓的音序器，早期机型用旋钮与按键编程，今天的软件鼓机仍沿用步进格的思路。

## Five languages

| Language | Name |
|---|---|
| Chinese | 鼓机 |
| English | drum machine |
| Italian | drum machine (from English; also macchina ritmica) |
| German | Drumcomputer / Rhythmusmaschine |
| French | boîte à rythmes |

A **drum machine** plays percussion sounds from a programmed sequence, generating them by synthesis or sampling. English names the machine, French boîte à rythmes calls it a "rhythm box", and German Drumcomputer files it under computers. Each name catches one face: machine, box, program.

**Watch out**: a drum machine is not a drum kit, and not the same as electronic drums. A kit is struck by a player, electronic drums are a playable electronic kit, while a drum machine is closer to a sequencer that drums; early models were programmed with knobs and buttons, and software drum machines still use the step grid.
