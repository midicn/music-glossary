::: zh
**知识共享许可（Creative Commons，CC）** 是一套**标准化的授权条款**，让创作者在保留部分权利的前提下允许他人使用。常见组合有 **BY**（署名）、**SA**（相同方式共享）、**NC**（非商业）、**ND**（禁止演绎）；**CC0** 则是放弃权利、进入公有领域的声明。

**常见误解是「CC 就是没有版权」**——CC 许可建立在版权之上，作者仍然拥有权利，只是预先给出了条件。**不同组合不能混用**：BY-NC 与 BY-SA 的义务不同；商用、改编、署名都要逐条确认。**看到 CC 标记，先看是哪一种 CC。**

::: en
**Creative Commons (CC)** is a set of **standard licences** that let creators allow reuse while keeping some rights. Common elements are **BY** (attribution), **SA** (share-alike), **NC** (non-commercial) and **ND** (no derivatives); **CC0** is a waiver placing a work in the public domain.

**The usual mistake is to think CC means "no copyright"** — CC licences are built on copyright; the author still holds rights and has simply granted conditions in advance. **The combinations are not interchangeable**: BY-NC and BY-SA carry different obligations; commercial use, adaptation and credit must each be checked. **When you see CC, first see which CC.**
