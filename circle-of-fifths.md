::: zh
**五度圈（circle of fifths）** 是把十二个调按**纯五度**排成一圈：C → G → D → A → E → B → F♯，再往另一边 C → F → B♭ → E♭ → A♭ → D♭。每走一步，调号就多一个升号或少一个降号；走满十二步回到起点。

它是一张**距离地图**：相邻的调只差一个升号，关系最近；隔得越远，共同音越少，转调越有「出远门」的感觉。常见误解是把它当成「和弦进行」——五度圈描述的是调与调的关系，**不是每首曲子都必须按它走**。

::: en
**The circle of fifths** arranges the twelve keys by **perfect fifths**: C → G → D → A → E → B → F♯, and the other way C → F → B♭ → E♭ → A♭ → D♭. Each step adds one sharp or removes one flat; twelve steps return to the start.

It is a **map of distance**: neighbouring keys differ by a single accidental and are closest; the further apart, the fewer the shared notes and the more a modulation feels like a journey. The usual mistake is to read it as a chord progression — the circle describes relations between keys, **not a route every piece must take**.
