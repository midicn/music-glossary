## 五语对照

| 语种 | 名称 |
|---|---|
| 中文 | 合成器 |
| 英语 | synthesizer |
| 意大利语 | sintetizzatore |
| 德语 | Synthesizer |
| 法语 | synthétiseur |

**合成器** 是用电子方式产生并塑造声音的设备或方法，名字来自希腊语 synthesis（合成）。意大利语 sintetizzatore、德语 Synthesizer、法语 synthétiseur 都指同一类东西。它可以是成排的模块，也可以是芯片里的一段算法；在常见的减法合成里，声音由振荡器、滤波器、包络等环节拼出来。

**常见混淆**：合成器不是某一台具体的琴，而是一类设备与方法的统称；「电子琴」通常指预设音色的电子键盘，不一定是合成器。中文「合成器」也容易与「音源」「采样器」混淆：采样器播放录好的声音，合成器则从波形开始塑造声音。

## Five languages

| Language | Name |
|---|---|
| Chinese | 合成器 |
| English | synthesizer |
| Italian | sintetizzatore |
| German | Synthesizer |
| French | synthétiseur |

A **synthesizer** is a device or a method for producing and shaping sound electronically, from Greek synthesis, "putting together". Italian sintetizzatore, German Synthesizer and French synthétiseur name the same class of instrument. It can be a rack of modules or a piece of code in a chip; in the common subtractive approach, oscillators, filters and envelopes build the sound.

**Watch out**: synthesizer is not the name of one particular keyboard but a category of instrument and technique. An electronic keyboard with preset sounds is not necessarily a synthesizer, and a sampler plays recorded sounds rather than shaping waveforms from the start.
