::: zh
**XY 立体声对（XY pair）** 把两支同型号、同指向的麦克风尽量靠近，振膜上下叠放，各自朝左右偏开，常见夹角为 90 至 120 度。两声道几乎同时收到声音，只留下强度差。

因为时间差接近零，XY 的单声道兼容性好，折叠后声像稳定，也不会因时间差产生明显梳状滤波。代价是宽度偏窄、纵深不如间隔式，且夹角越大中间越空。它适合房间反射强或需要干净中心的场合。

常见误解是以为 XY 一定要成 90 度。夹角与指向要配合声源宽度；振膜无法完全重合，极近的高频仍会有细微差异。
:::

::: en
An **XY pair** places two matched microphones as close as possible, capsules stacked, each angled to one side, commonly between 90 and 120 degrees. Both channels receive the sound almost simultaneously, leaving level difference as the main cue.

With near-zero time difference, XY folds to mono well: the image stays stable and comb filtering from arrival time is minimal. The trade-off is a narrower image and less depth than spaced methods, and a wider angle can hollow out the centre. It suits reflective rooms or sources that need a solid centre.

The usual mistake is assuming XY must be 90 degrees. Angle and pattern should match the source width; capsules cannot occupy exactly the same point, so slight high-frequency differences remain.
:::
