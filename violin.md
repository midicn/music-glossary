## 五语对照

| 语种 | 名称 |
|---|---|
| 中文 | 小提琴 |
| 英语 | violin |
| 意大利语 | violino |
| 德语 | Violine / Geige |
| 法语 | violon |

**小提琴** 是弦乐四重奏与管弦乐队的核心高音乐器。意大利语 violino 是「小 viola」的意思；德语除了 Violine，日常也说 **Geige**——**同一个乐器，正式名与民间名并存**。中文旧译「梵婀玲」是 violin 的音译，今天只在文学作品里见到。

**常见混淆**：viola 在意大利语里是中提琴，不是小提琴；英语的 violin 与 fiddle 指同一件乐器，只是场合不同。

## Five languages

| Language | Name |
|---|---|
| Chinese | 小提琴 |
| English | violin |
| Italian | violino |
| German | Violine / Geige |
| French | violon |

The **violin** is the core high instrument of the string quartet and the orchestra. Italian violino means "small viola"; German also uses the everyday **Geige** — **one instrument with a formal and a vernacular name**. The old Chinese transliteration 梵婀玲 survives only in literature.

**Watch out**: Italian viola is the viola, not the violin; English violin and fiddle name the same instrument in different settings.
